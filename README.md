## 🚀 Sobre o Projeto

O **Convert Money** é uma ferramenta prática desenvolvida para praticar e consolidar conceitos fundamentais do **JavaScript**, como manipulação do DOM, manipulação de eventos e cálculos dinâmicos de conversão de valores entre diferentes moedas.

---

## ✨ Funcionalidades

- **Conversão de Valores:** Converte Real (BRL) para moedas estrangeiras (como Dólar, Euro, etc.).
- **Atualização Dinâmica de Interface:** Troca de bandeiras/símbolos e atualização instantânea dos valores formatados na tela ao alterar a moeda selecionada.
- **Design Responsivo:** Layout adaptado para diferentes tamanhos de telas e dispositivos.
